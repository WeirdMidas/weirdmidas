### My main projects currently 🥱
- 🐦 [SkyScene](https://github.com/WeirdMidas/SkyScene-Addon) - A memory management optimization module, aiming for maximum efficiency and stability in memory management within the Android environment
- 🧭 [lmkd psi mod(fied](https://github.com/WeirdMidas/lmkdpsimod) - A background process management optimization module, optimizing how lmkd psi manages processes to be more efficient and accurate for decent multitasking
- ♥️ [Perfd-opt](https://github.com/WeirdMidas/perfd-opt) - An EAS scheduling optimization module for devices with Snapdragon SoCs. Unlike uperf, it focuses on optimizing the framework, scheduling, and deeper layers of each device individually
- 💢 [Uperf](https://github.com/WeirdMidas/uperf) - A user-space custom scheduler that, unlike its direct rival perfd-opt, aims to deliver higher performance headroom on Snapdragon SoCs. Through direct control over scheduling, frequency decisions, and more, the performance gains from this project are enormous.
